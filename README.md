# CCS Blockchain Node Operations

## Overview

Infrastructure engineering and security documentation developed
through Croydon Computer Service (CCS).

The engineering laboratory includes:

- Bitcoin Core mainnet infrastructure
- Lightning Network Daemon (LND)
- Algorand node infrastructure
- Ubuntu Linux administration
- Infrastructure health monitoring
- Network security and operational resilience

## Engineering Objectives

1. Monitor infrastructure health and service availability.
2. Assess blockchain synchronisation and connectivity.
3. Apply appropriate Linux and network security controls.
4. Document backup and recovery procedures.
5. Produce reproducible engineering evidence.

## Technologies

Ubuntu Linux, Bitcoin Core, LND, Algorand, Bash, Python,
systemd, nftables, Tailscale and LUKS2.

## Repository Contents

- scripts-bash/ — Historical monitoring and automation examples
- docs/ — Architecture and engineering documentation
- README.md — Project overview

Some scripts and documentation describe earlier laboratory
configurations and require review before reuse.

## Engineering Methodology

CCS follows an evidence-based approach:

Situation → Task → Action → Result → Evidence

Engineering activities emphasise controlled implementation,
verification, documentation and operational accountability.

## Security Notice

This repository is an educational and engineering portfolio.

It must not be used to publish production credentials,
private keys, confidential client information or live
operational monitoring records.

Scripts must be reviewed and adapted before execution.
